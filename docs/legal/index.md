# Legal Information

GraphAide includes important legal documents that govern its use, licensing, and terms.

## Official Legal Files

All legal documents are maintained in the repository root for authenticity and to ensure a single authoritative source:

| Document | Purpose | Location |
|----------|---------|----------|
| **[LICENSE.txt](https://github.com/pnnl/GraphAide/blob/develop/LICENSE.txt)** | BSD 2-Clause License | Repository root |
| **[DISCLAIMER](https://github.com/pnnl/GraphAide/blob/develop/DISCLAIMER)** | Government disclaimer & liability limitations | Repository root |
| **[ACKNOWLEDGMENT](https://github.com/pnnl/GraphAide/blob/develop/ACKNOWLEDGMENT)** | Credits, funding, citations | Repository root |
| **[NOTICE](https://github.com/pnnl/GraphAide/blob/develop/NOTICE)** | Software identification & legal notices | Repository root |

## Quick Overview

### License
- **Type:** BSD 2-Clause (Simplified BSD License)
- **Key Rights:** Use, modify, distribute (including commercial)
- **Key Obligations:** Include license text, attribute copyright

### Disclaimer
- **Scope:** Government disclaimer required by DOE funding
- **Key Point:** Software provided "as is" with no warranties
- **Liability:** Developers not liable for damages from use

### Acknowledgment
- **Content:** Authors, contributors, funding sources
- **Research Citation:** BibTeX format for academic papers
- **Dependencies:** Recognition of open-source projects

### Notice
- **Content:** Software ID, restrictions, export control statements
- **Compliance:** Data privacy, government rights
- **Terms:** Export control, permitted/prohibited uses

## For Different Users

### Developers
- Read **LICENSE.txt** to understand usage rights
- Review **NOTICE** for export control and restrictions

### Researchers
- Use the citation from **ACKNOWLEDGMENT** in papers
- Credit PNNL and DOE in your research

### Legal/Compliance Teams
- Review **NOTICE** for comprehensive legal terms
- Check **DISCLAIMER** for liability framework

### End Users
- Review **DISCLAIMER** before using in production
- Understand warranty limitations and validation requirements
